# The entries that `check:jq-args` lets take a shell expansion (#7091). Each
# entry is an option of jq and the name of its argument. The value of each
# name here is small: a number, a boolean, null, a ref, a path, a date or a
# name. The kernel refuses one argument past 128 KiB. So a value of unbounded
# size, such as a body, a report or a list from GitHub or git, goes to jq in a
# file with `--slurpfile` or `--rawfile`. A new small name joins this list in
